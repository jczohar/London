# לונדון – מידע למטייל (PWA)

## התקנה מהירה
1. העלו את כל הקבצים לתיקייה אחת בשרת HTTPS (או פתחו מקומית עם שרת מקומי).
2. פתחו `index.html` בדפדפן.
3. במובייל: "הוסף למסך הבית" / Install app.

## קבצים
- `index.html` / `London_Guide.html` – האפליקציה
- `manifest.json` – הגדרות PWA
- `sw.js` – Service Worker (עבודה חלקית ללא רשת)
- `icon-192.png`, `icon-512.png` – אייקונים

## הערה
PWA מלא (התקנה + offline) דורש הגשה דרך HTTPS (לא file://).
מזג אוויר, שער מטבע ותמונות דורשים חיבור לאינטרנט.
